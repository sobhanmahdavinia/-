# پایش مصرف

برنامه‌ی اندروید برای تعیین سقف مصرف روزانه‌ی هر برنامه و قفل کردن آن تا ساعت ۰۰:۰۰.

## بیلد با گیت‌هاب (بدون Android Studio)
1. یک مخزن جدید در GitHub بسازید و همه‌ی فایل‌های این پوشه را در آن push کنید (شاخه‌ی `main`).
2. تب **Actions** ← workflow به اسم **Build APK** خودکار اجرا می‌شود (یا از «Run workflow» دستی اجرا کنید).
3. بعد از حدود ۵ تا ۸ دقیقه، در پایین صفحه‌ی اجرا، بخش **Artifacts** فایل `PayeshMasraf-apk` را دانلود کنید و APK را نصب کنید.
4. برای انتشار به‌صورت Release: یک تگ مثل `v1.0` بزنید؛ APK در بخش Releases قرار می‌گیرد.

APK با کلید ثابتِ داخل مخزن (`app/payesh.jks`) امضا می‌شود، پس هر بیلد جدید روی نسخه‌ی قبلی نصب می‌شود.
اگر مخزن را عمومی می‌کنید، کلید خودتان را جایگزین کنید.

## راه‌اندازی روی گوشی
برنامه را باز کنید و چهار مورد بالای صفحه را فعال کنید: آمار مصرف، سرویس دسترسی‌پذیری، مدیر دستگاه، بدون محدودیت باتری.
در اندروید ۱۳ به بالا برای فعال شدن دسترسی‌پذیری اول باید «Allow restricted settings» را از صفحه‌ی اطلاعات برنامه (منوی سه‌نقطه) بزنید.
